# Русский кастомный голос через Qwen3-TTS Base

LiveTalking использует отдельный сервер vLLM-Omni с моделью `Qwen/Qwen3-TTS-12Hz-1.7B-Base`. Модель клонирует голос по WAV-записи и точной расшифровке. Дообучение для первого запуска не требуется.

## 1. Подготовьте образец

Запишите одного говорящего без музыки и сильного эха в WAV-файл, например `voice.wav`. Запишите **дословно** произнесённый текст: пунктуация тоже помогает модели. Используйте только свой голос или голос человека, разрешившего его использование.

## 2. Запустите сервер Qwen3-TTS

Установите vLLM-Omni в отдельном окружении Python 3.12 по [официальной инструкции](https://docs.vllm.ai/projects/vllm-omni/en/latest/getting_started/quickstart/). Не устанавливайте его поверх окружения LiveTalking: у vLLM свои требования к PyTorch и CUDA.

```bash
vllm serve Qwen/Qwen3-TTS-12Hz-1.7B-Base \
  --omni --deploy-config vllm_omni/deploy/qwen3_tts.yaml \
  --trust-remote-code --enforce-eager --port 8091
```

Серверу нужен работающий GPU и доступ к весам модели при первой загрузке. Проверьте, что он отвечает: `curl http://127.0.0.1:8091/v1/models`. Для менее мощной видеокарты можно заменить `1.7B` на `0.6B` в команде сервера.

## 3. Запустите LiveTalking

Из каталога `LiveTalking` в его обычном окружении:

```bash
python app.py \
  --tts qwen3tts \
  --TTS_SERVER http://127.0.0.1:8091 \
  --REF_FILE /полный/путь/к/voice.wav \
  --REF_TEXT 'Дословная расшифровка записи голоса.'
```

Адаптер отправляет образец по API `/v1/audio/speech` с `task_type=Base`, `language=Russian` и потоковым PCM. Выход модели 24 кГц преобразуется в кадры 16 кГц для аватара. Файл `config.yaml` менять не требуется: параметры командной строки переопределяют его значения.

Если у вас несколько одновременных сессий, следите за доступной памятью GPU и задержкой первого аудиофрагмента. Качество голоса проверяйте на коротких русских фразах, включая вопросы, числа и имена.
